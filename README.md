# 指纹浏览器里不同环境的 Cookie 互通吗？

在「指纹浏览器」的独立普通环境中，网站会话可以分开保存。在同一环境开两个普通标签页，则可能继续使用该站点同一份 Cookie。先分清自己是换了标签，还是换了工作环境。
[官网操作说明](https://zwbrowser.com/help/desktop/privacy/)

![工作环境里的网页与数据菜单](https://zwbrowser.com/images/help-desktop-privacy.webp)

## 用两个演示账号验证

给 A、B 两个环境分别命名，从各自窗口打开同一测试网站，各用不同账号登录。两边刷新后对照头像。关闭 A 窗口再重新打开，记录 A 是否要求验证，同时看 B 能否正常工作。

## 为什么看起来仍像同一账号？

先核对是否从同一环境重复打开，或两边实际登录了同一个网站身份。直接导入相同会话文件也会影响测试结果。排查时使用普通演示账号即可；会话文件可能包含有效登录信息，不适合在团队群或文章截图中展示。
